# ФСП Career — платформа обратного найма ИТ-специалистов

Цифровая платформа-агрегатор ИТ-вакансий с верифицированным профилем достижений
участника Федерации спортивного программирования.

**Кандидат не откликается вслепую** — он распределяется в категорию «специализация + грейд»,
которую присваивает адаптивный тест, а не строчка в резюме.
**Работодатель не фильтрует поток откликов** — он описывает потребность, получает подборку
с объяснением каждой позиции и сам выходит на конкретного человека с предложением и вилкой зарплаты.
**Контакты закрыты по умолчанию** и раскрываются только после согласия кандидата.

## Быстрый старт

```bash
docker compose up --build
```

Миграции и демо-данные накатываются автоматически при старте контейнера `api`.

## Сквозной сценарий за две минуты

1. Войти работодателем → **Потребности и подборки** → открыть подборку
   «Senior Python в платформенную команду».
2. Развернуть **«Почему этот кандидат здесь»** — балл разложен на пять компонентов
   с объяснением каждого.
3. Уточнить запрос фильтрами → **«Сбросить фильтры»** возвращает исходную выдачу:
   уточнение не пересобирает подборку.
4. **Пригласить** кандидата с вилкой зарплаты — контакты в карточке закрыты.
5. Войти как `anna.belova@fsp.example` → **Приглашения** → «Принять и открыть контакты».
6. Вернуться к работодателю — статус `accepted`, контакты открыты.

## Что реализовано

**Кандидат.** Профиль вручную или загрузкой PDF-резюме с автораспознаванием (ФИО, контакты,
стек, роли, софт-скиллы, стаж); выгрузка стандартизированного PDF-профиля; опрос и адаптивное
тестирование с присвоением категории; несколько специализаций независимо друг от друга;
инбокс приглашений с принятием/отклонением; регулярные короткие задания; вакансии и отклики;
привязка ФСП ID; настройки приватности и журнал раскрытия контактов.

**Работодатель.** Профиль компании; описание потребности своими словами с автоизвлечением
стека из текста; подборка кандидатов по категориям с объяснимостью; уточнение запроса без
потери выдачи; поиск по банку кандидатов; приглашения с обязательной вилкой и отслеживанием
статусов; публикация вакансий и работа с откликами; регулярные задания и ответы на них.

**Механики.** IRT 2PL + CAT с правилом остановки, учитывающим расстояние до границы грейда;
720 активных шаблонов заданий с генерацией из `(template, seed)` и серверной проверкой;
двухстадийный подбор (маршрутизация в категории → ранжирование по пяти компонентам);
оценка силы профиля ФСП с учётом уровня, места, размера поля и свежести.

## Архитектура

```
frontend/  React 19 + TypeScript + Vite, дизайн-система по брендбуку ФСП
backend/   FastAPI-монолит: api / schemas / services / domain / models / db
           domain/ — чистые функции без БД и HTTP: IRT, подбор, ФСП, резюме, навыки
data/      синтетические данные, разметка, артефакты валидации
docs/      сопроводительная документация
```

Правило слоёв: верхние знают о нижних, нижние о верхних — никогда. Доменные механики
не импортируют SQLAlchemy и FastAPI, поэтому офлайн-валидация прогоняет ровно тот же
код, который работает в API.
